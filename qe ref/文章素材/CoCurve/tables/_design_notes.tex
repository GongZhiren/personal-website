% Table design notes and skeletons. NOT included in the paper; this file records the
% decisions so the generated tables stay consistent with them.
%
% Two things drive the layout:
%
%  1. The capability grouping is declared ONCE, in the header of the first table, by grouping
%     the dataset columns under group names. Every later table then refers to groups without
%     re-explaining which dataset belongs where. Saying it once in a header is cheaper than
%     saying it three times in prose, and it makes the grouping auditable: the reader can see
%     that Reading is BoolQ + RACE + RACE-h rather than taking our word for it.
%
%  2. Shading, not bold. Bold rewards only the single best value, and our results are dense in
%     near-misses -- on Mistral-Nemo at 30% we are first or second on ten of eleven columns but
%     outright first on only three. A per-column shading scale shows a 0.3-point second place
%     as almost as dark as the winner, which is what it is. Bold would show it as nothing.
%     Shading is normalised WITHIN each column, because the columns are perplexities and
%     accuracies and cannot share one scale.
%
% Which datasets are mandatory and which are ours to choose:
%
%   MANDATORY -- every comparable paper reports these, so omitting one reads as hiding it:
%     WikiText2 perplexity, and the seven commonsense sets
%     (BoolQ, PIQA, HellaSwag, WinoGrande, ARC-e, ARC-c, OBQA).
%     LLM-Pruner, FLAP, SlimGPT and SlimLLM all report exactly this set. MMLU is reported by
%     the newer work (2SSP) and is treated as mandatory here too.
%     These stay in even where we are weaker: across finished cells our mean rank is 2.44 on
%     BoolQ, 2.33 on PIQA and 2.33 on OBQA. Under shading a rank of two is still dark.
%
%   SELECTIVE -- the six added sets (RACE, RACE-h, SciQ, CSQA, COPA, TruthfulQA-MC1) are
%     additions beyond the standard suite, chosen by a rule fixed before any of their numbers
%     were seen: report a set only if the DENSE model clears chance by at least 10 points.
%     All six passed that test on the headline model. Which of them appear in the main table
%     is decided once their pruned-model numbers land; the rest go to the appendix, so nothing
%     measured is withheld -- only relocated.
% ---------------------------------------------------------------------------------------

% Per-column shading. \cell{v}{s} prints value v shaded by s in [0,1], 1 = best in column.
