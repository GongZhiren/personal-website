# AnchorPath — AAAI-2027 submission package

Three **independent, self-contained** documents (no cross-document references):

| File | What it is | Length |
|------|------------|--------|
| `main.tex` → `main.pdf` | Main paper. Content on pp. 1–7; references only on pp. 7(bottom)–9. Contains **no** reference to the appendix/supplement. | 9 pp (7 content) |
| `supplement.tex` → `supplement.pdf` | Technical Supplement. Opens with a self-contained notation/results recap, then the full appendix (proofs, protocol, complete results). | 15 pp |
| `ReproducibilityChecklist.tex` → `.pdf` | AAAI reproducibility checklist, every applicable item answered. | 2 pp |

The **Code and Data Supplement** is a separate directory (`../code_supplement/`).

## Build

```bash
bash build.sh          # builds all three PDFs (needs a TeX install + pdflatex/bibtex)
```

or per document: `pdflatex X → bibtex X → pdflatex X → pdflatex X`.

## Notes

- Template: AuthorKit27 (`aaai2027.sty` / `aaai2027.bst`). Fonts are loaded by the
  style file — do **not** add `times`/`helvet`/`courier`.
- Anonymous: author block is `Anonymous Submission` in all documents.
- `main.tex` and `supplement.tex` each `\bibliography{refs}` independently.
- Figures are regenerated by `make_figs.py` (matplotlib only) into `figs/`.
